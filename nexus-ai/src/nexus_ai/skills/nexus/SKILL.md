# Nexus Workspace Operations

Use this skill when the user asks about workspace state, projects, notes, chat, calendar, or dashboard data.

Guidelines:
- Prefer Nexus MCP tools over local guesses.
- Read before writing.
- Summarize tool results with exact entity names and ids when useful.
- Do not claim a mutation succeeded unless the MCP tool returned success.
